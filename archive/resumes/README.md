# Resume Archive

이 디렉터리는 기준 이력서, 지원 회사별 이력서, 채용 플랫폼 입력본을 목적에 따라 분리해 관리한다.

```text
archive/resumes/
├── original/                  # 모든 이력서의 기준이 되는 원본
├── companies/<company>/       # 특정 채용공고에 맞춘 회사별 지원서
├── platforms/<platform>/      # 사람인 등 채용 플랫폼의 입력용 문안
├── README.md                  # 디렉터리 구조 안내
└── CUSTOMIZATION_RULES.md     # 이력서 수정 및 검증 규칙
```

## 디렉터리별 역할

### `original/`

- 사실관계와 전체 경력을 관리하는 기준 이력서다.
- 회사별 지원서나 플랫폼 입력본을 만들 때 이 디렉터리의 내용을 원본으로 사용한다.
- 지원처에 맞춘 수정은 원본에 직접 반영하지 않는다.

### `companies/<company>/`

- 특정 회사와 채용공고에 맞춘 HTML·PDF 이력서를 보관한다.
- 직무 타이틀, 기술 순서, 경력 강조점, 프로젝트 순서를 채용공고에 맞춰 조정한다.
- 면접 가이드처럼 해당 지원처에만 필요한 자료도 회사 디렉터리 안에 둔다.

### `platforms/<platform>/`

- 채용 플랫폼의 섹션 구조에 맞춘 복붙용 문안을 보관한다.
- 플랫폼은 지원 회사가 아니므로 `companies/` 아래에 두지 않는다.
- 동일한 회사 프로젝트를 `경력`과 `경험 / 활동 / 교육`에 중복 작성하지 않는다.
- 플랫폼 입력 내용도 `original/`의 사실관계를 기준으로 유지한다.
